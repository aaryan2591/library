# 📚 Library

A simple book-tracking app — add books to your shelf, mark them as 
read or unread, and remove the ones you're done with. Built while 
learning objects and constructors in JavaScript.

🔗 [Live Demo](https://aaryan2591.github.io/library/)

<img width="800" alt="Library App showing book list" src="https://github.com/user-attachments/assets/2c0f9171-2ffc-436e-8ec5-52735680d973" />

## Features

- Add a book via a modal dialog (title, author, page count, status)
- Mark any book as **Read** or **Unread**
- Remove books from your shelf
- Each book gets a unique ID

## Built with

- HTML
- CSS
- JavaScript (constructor functions / object-oriented approach)

## What I practiced

- Object and constructor functions
- Working with the native `<dialog>` element for modals
- DOM manipulation and rendering data dynamically
- Form handling and validation
